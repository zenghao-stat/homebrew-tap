# zenghao-stat Homebrew Tap

## Install apple-mail-cli

```bash
brew install zenghao-stat/tap/apple-mail-cli
```

Or tap the repository first:

```bash
brew tap zenghao-stat/tap
brew install apple-mail-cli
```

In a `Brewfile`:

```ruby
tap "zenghao-stat/tap"
brew "apple-mail-cli"
```
